Jackal Builder Full

Install:
1. Extract this ZIP.
2. Copy everything into your Fiaz-website-clean folder.
3. Replace files when Windows asks.
4. Commit in GitHub Desktop: Install Jackal Builder Full
5. Push origin.
6. Wait for Cloudflare Pages to deploy.
7. Open /admin.

Features:
- Visual preview inside the admin
- Click text on the website preview and edit it
- Drag-and-drop section ordering
- Layout controls for spacing, card columns, image sizes and widths
- Content manager for images, services, results, packages and FAQs
- Save through existing Cloudflare Functions + GitHub token
