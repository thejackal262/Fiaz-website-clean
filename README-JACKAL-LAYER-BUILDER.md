Jackal Layer Builder

Install:
1. Extract this ZIP.
2. Copy everything into Fiaz-website-clean.
3. Replace files when asked.
4. GitHub Desktop summary: Install Jackal Layer Builder
5. Commit to main.
6. Push origin.
7. Wait around 60 seconds.
8. Open /admin.

What changed:
- The website is now rendered from content/layers.json.
- Every item is its own layer.
- Text, buttons, cards and images can move independently.
- Resize handles are per layer.
- Layers can move forward/back, lock, hide, duplicate and delete.
- Publish writes layers.json to GitHub through /api/layers.
