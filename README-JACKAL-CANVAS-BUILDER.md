Jackal Canvas Builder

Install:
1. Extract this ZIP.
2. Copy everything into Fiaz-website-clean.
3. Replace files when asked.
4. GitHub Desktop summary: Install Jackal Canvas Builder
5. Commit to main.
6. Push origin.
7. Wait around 60 seconds.
8. Open /admin.

Use:
- Click text, image, card or section.
- Drag images directly to crop/reposition.
- Mouse wheel on image zooms it.
- Drag yellow handles to resize boxes/cards/sections.
- Use Text + / Text - to resize text.
- Use Sections to reorder sections.
- Publish when happy.
