Jackal Freeform Builder

Install:
1. Extract this ZIP.
2. Copy everything into Fiaz-website-clean.
3. Replace files when asked.
4. GitHub Desktop summary: Install Jackal Freeform Builder
5. Commit to main.
6. Push origin.
7. Wait around 60 seconds.
8. Open /admin.

Use:
- Tap anything.
- Drag it to move it.
- Drag yellow handles to resize.
- Text + / Text - resizes text.
- Image + / Image - resizes image crop.
- No mouse wheel zoom.
- Replace image uploads a new image.
- Delete hides the selected element.
- Front/Back changes layering.
- Publish saves to GitHub/Cloudflare.
