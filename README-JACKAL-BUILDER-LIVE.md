Jackal Builder Live

Install:
1. Extract this ZIP.
2. Copy everything into Fiaz-website-clean.
3. Replace files when asked.
4. GitHub Desktop summary: Install Jackal Builder Live
5. Commit to main.
6. Push origin.
7. Wait around 60 seconds.
8. Open /admin.

How to use:
- Click text on the website to edit or resize it.
- Click hero/about/result images to select them.
- Drag the selected image directly on the page to reposition it live.
- Mouse wheel over image = zoom/crop live.
- Double-click image = reset.
- Use Replace image to upload a new image.
- Use Sections to drag section order.
- Press Publish when happy.
